# Gemini へのプロンプト：英熟語ターゲット1000 データ作成依頼

## 使い方

1. Gemini に動画ファイル（100熟語分）をアップロードする
2. 以下のプロンプトをコピーして送信する
3. `{開始番号}` `{終了番号}` を実際の番号に置き換える（例: 0001, 0100）

---

## プロンプト

添付の動画は「旺文社・英熟語ターゲット1000（5訂版）」の熟語番号 {開始番号} ～ {終了番号} のページをめくりながら撮影したものです。

この動画から、各熟語のデータを読み取り、以下の仕様に従って **1つのJSONファイル** として出力してください。

### 出力形式

ルート要素は配列で、各要素が1つの熟語に対応します。

```json
[
  {
    "number": "0001",
    "idioms": ["a piece of ~"],
    "means": [
      {
        "idiom-jp": "１つの～",
        "synonyms": ["one"],
        "example-sentence": "I handed him a piece of paper so that he could write down all the names.",
        "sentence-jp": "彼がすべての名前を書けるように私は彼に1枚の紙を手渡した。"
      }
    ],
    "notes": [
      "不可算名詞を「数量化」する最も一般的な句。",
      "「数量化」を表す他の例は「深める」P.74。"
    ]
  },
  {
    "number": "0002",
    "idioms": ["a couple of ~"],
    "means": [
      {
        "idiom-jp": "２つの～",
        "synonyms": ["two"],
        "example-sentence": "My mother wanted me to buy a couple of sandwiches on my way home.",
        "sentence-jp": "母は私に、帰宅の途中で2個のサンドイッチを買ってきてもらいたかった。"
      },
      {
        "idiom-jp": "２、３の～",
        "synonyms": ["a few ~"],
        "example-sentence": "Take a couple of sweaters with you; it might be cold up there.",
        "sentence-jp": "２、３枚のセーターを持っていきなさい。その上の方は寒いかもしれません。"
      }
    ],
    "notes": [
      "①②の区別が明確でない場合も多い。米ではofが省略されることもある。"
    ]
  }
]
```

### 各フィールドの説明

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `number` | string | ○ | 熟語番号。4桁ゼロ埋め（例: `"0001"`, `"0100"`） |
| `idioms` | string[] | ○ | 見出しの英熟語。同義の熟語が複数ある場合は配列に複数入れる（例: `["a great deal of ~", "a good deal of ~"]`） |
| `means` | object[] | ○ | 意味の配列。意味が複数ある場合は複数要素になる |
| `means[].idiom-jp` | string | ○ | 日本語の意味 |
| `means[].synonyms` | string[] | − | 同義語・類義語がある場合のみ記載。なければフィールド自体を省略 |
| `means[].example-sentence` | string | ○ | 英語の例文 |
| `means[].sentence-jp` | string | ○ | 例文の日本語訳 |
| `notes` | string[] | − | 補足説明・注意事項がある場合のみ記載。なければ空配列 `[]` |

### 読み取りルール

1. **熟語番号と見出し語**: ページ上部の番号と太字の英熟語を読み取ってください。
2. **意味**: 丸数字（①②など）で区切られた日本語の意味をそれぞれ `means` の要素にしてください。
3. **同義語（synonyms）**: 意味の横や下に `= ～` や `≒ ～` の形で記載されている語句があれば `synonyms` に入れてください。なければフィールドごと省略してください。
4. **例文**: 各意味に対応する英語の例文とその日本語訳を正確に転記してください。
5. **補足説明（notes）**: 例文の下や欄外に小さい字で書かれている補足・注釈・参照情報を `notes` に入れてください。
6. **熟語が複数**: 1つの番号に対して見出し語が複数ある場合（例: "a great deal of ~" と "a good deal of ~"）は `idioms` 配列に全て入れてください。
7. **読み取れない箇所**: 動画のブレやピンボケで読み取れない箇所がある場合は、該当フィールドに `"[読取不可]"` と記載し、その熟語の末尾に `"notes"` として `"[要確認] 一部読み取り不可の箇所あり"` を追加してください。

### 出力に関する注意

- **正確性**: 動画に映っている内容をそのまま転記してください。推測や補完はしないでください。
- **文字**: 全角・半角の区別は書籍の表記に従ってください。
- **順番**: 熟語番号の昇順で出力してください。
- **JSON形式**: 有効なJSONとして出力してください。コメントは含めないでください。
- **出力量**: 指定範囲（{開始番号} ～ {終了番号}）の全熟語を漏れなく出力してください。出力の途中で切れる場合は「続きを出力してください」と伝えますので、途切れた箇所から続きを出力してください。
